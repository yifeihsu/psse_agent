# Generated Artifacts

Generated datasets and run outputs are grouped here so the repository root stays focused on source code.

- `measurements/`: generated MATPOWER/OpenDSS measurement datasets.
- `traces/`: generated SFT/tool-use trace datasets and inspection subsets.
- `eval_archives/`: archived evaluation outputs and packaged review artifacts.
- `logs/`: Slurm and local run logs.

Keep source JSONL inputs under `data/`, model checkpoints under `outputs/`, and code under the existing source directories.
