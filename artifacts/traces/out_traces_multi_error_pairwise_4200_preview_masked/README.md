Representative inspection subset from `data/sft_with_tools_multi_error_pairwise_4200_hardened_masked.jsonl`.

- `sft_traces.representative_2_per_combo.jsonl`: 2 traces for each of the 6 pairwise combos.
- `sft_traces.hardening_representative_2_per_template.jsonl`: 2 traces for each hardening template, with intentionally invalid helper calls marked `trainable: false`.
- `sft_traces.representative_2_per_combo_plus_hardening.jsonl`: combined inspection file.
