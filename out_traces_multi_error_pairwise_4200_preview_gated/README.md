# Gated Multi-Error Pairwise Preview

Representative inspection subset generated after adding scoped M/P/T/H tools, `trace_type`, loss-mask aliases, family-keyed hints, detailed hardening steps, and residual diagnosis status.

- `sft_traces.representative_2_per_combo.jsonl`: 2 accepted traces for each of the 6 pairwise combos.
- `sft_traces.hardening_representative_2_per_template.jsonl`: 2 accepted hardening traces for each tool-precondition template.
- `sft_traces.representative_2_per_combo_plus_hardening.jsonl`: combined 18-row review file.
- `representative_summary.tsv`: compact table for quick inspection.
