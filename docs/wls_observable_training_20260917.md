# WLS-observable expert training admission

The reviewed physical population contains real faults that remain quiet under
balanced WLS. Training now has a separate admission step: positive examples
must produce current WLS evidence and an executable, evidence-supported expert
decision. Healthy controls use their own quiet-WLS/safe-finalization rule.
The physical populations and unfiltered evaluation cases remain available.

## Measured detection

Fresh detection used the actual generated noisy observations, the declared
covariance, and the unchanged research rule:

`J >= chi2.ppf(0.99, dof) OR max(abs(normalized_residual)) >= 4`.

For 95 degrees of freedom the global threshold is 129.9726787. Exact structural
rows in the node/breaker adapter remain constraints; no small artificial sensor
variance replaces them. No offline noiseless energy or paired clean distance is
substituted for the actual WLS alarm.

Each main view has 58 source windows from four physical parents, expanded to
124 noisy observations: 108 faulted and 16 healthy. Healthy false alarms are
1/16 for each accuracy view, from the same paired noise trial; calibration
controls are 0/10. These small correlated samples are not a population
false-alarm calibration.

The separate weak-HIF evaluation cohort is 0/4 detected under each profile.
Low-THD harmonic cases are 0/3 per voltage convention/profile. Severe harmonics

are 0/3, 0/3, and 3/3 as power sigma decreases. Full node/breaker dangling and
split cases are each 3/3 per profile, with 0/4 healthy alarms. The complete
audit covers 936 observations with no solver failures.

## Training rules

`research/filter_reviewed_training.py` applies these rules only to training
parents:

1. Materialize exactly the same noise stream as the dataset loader, including
   explicit paired-noise groups. Keep the resulting observation fixed.
2. Require a converged WLS alarm for a physically labelled fault. Exclude quiet
   faults. Retain quiet healthy controls only after actual expert finalization;
   exclude healthy false alarms from training while still reporting them.
3. For a mixed physical fault plus meter error, also require alarms in the
   physical-only and meter-only counterfactuals under the **same noise**. Known
   component means are used only in this offline selection audit, never as
   expert inputs. A large meter error cannot make a quiet HIF component qualify.
4. Run the existing observable expert in the real 40-action research environment,
   with GNN screening disabled and no relay/fault-family flags. Require a
   process-valid action to execute and return actual available evidence or
   state-bound supported context. Successful but unavailable acquisition replies
   do not qualify by themselves.
5. Export the executed decision through the canonical SFT converter with aliases
   applied before compaction. Parent identity, split, observation/case/covariance
   hashes and the prefix-only scope remain in metadata outside the prompt.

Additional phase observations are generated by replaying the saved corrected
physical circuit. The reconstructed exact SCADA vector must match the stored
source mean after its documented meter offset is removed, to 1e-8 pu. Only
fresh noisy phase voltage/current sensors and their covariance are supplied to
the environment. Labels, fault settings, clean aliases and model-generation
receipts remain private to the selection audit. The existing sampled SCADA
vector is neither replaced nor re-noised.

The GNN case contains only its allowed network fields. Expert execution also
requires public operator limits/generator configuration, restored from the same
reported parent for every variant. The private changed physical model is never
substituted as the expert's reported case, and VM/VA initialization is flat.

The baseline exclusions are seven quiet pure-HIF windows, one mixed window with
a quiet HIF component, and one healthy false alarm. Each view retains all five
fault families and a healthy negative. Accuracy views are separate experiments;
the filter does not choose one automatically or retune thresholds.

Harmonic training companions retain 10/18 rows, including controls; eight quiet
fault rows are excluded. Full node/breaker companions retain 9/9 rows. Their
expert prefixes stay in separate schema adapters: harmonic labels are not
silently added to the five-family GNN, and constrained node/breaker measurements
are not passed to its positive-diagonal-covariance graph builder.

Artifacts are under `output/reviewed_wls_admission_20260917/filtered_v1/`:

- `baseline/filtered_manifest.jsonl` is the baseline **GNN training input**:
  admitted fixed training observations plus unchanged held-out source rows.
- `baseline/training_manifest.jsonl` contains only admitted training windows;
  it is not a complete train/validation input by itself.
- `baseline/expert_prefixes.chat_sft.jsonl` contains **LLM next-action SFT**
  targets. Equivalent files exist for the two accuracy profiles and companions.
- `excluded_training_manifest.jsonl` retains physical labels and reasons.
  Excluded training-parent cases are not relabeled healthy or treated as a new
  held-out evaluation population.
- `admission_ledger.jsonl` records actual WLS, counterfactual checks, expert
  observations, actions, evidence checks and execution results.
- `consumer_validation.json` records successful canonical-chat and teacher
  realizability audits and the GNN training-admission checks.

The GNN training entry point rejects unfiltered `reviewed_v1` training rows and
any admitted row whose observation, covariance, or reported model has changed.
Admitted rows use `measurement_kind="observed"` and cannot be re-noised. Legacy
benchmarks and all validation/calibration/test rows retain their original rules.

New `research.reviewed_fault_scenarios` bundles perform training admission by
default and publish `default_training_inputs`. `--no-training-admission` creates
only the raw physical population for audits; those rows remain unqualified for
reviewed training. To filter an existing bundle into a new directory:

```powershell
python -m research.filter_reviewed_training --bundle output/reviewed_fault_scenarios_20260917/validated_bundle --output-dir output/new_wls_qualified_training
```

## Scope of the evidence

Admission certifies the first executable, evidence-supported expert decision
prefix, often acquisition of more measurements. It does **not** certify final
fault-family identification, parameter identifiability, or complete physical
repair within 40 steps. In particular, this work does not produce a new success
rate for full expert episodes or train a model.

The training population is intentionally conditional on detectable and actionable
observations. Evaluation stays unfiltered so quiet HIFs and other weak cases
still expose the system's limits. These pilot counts are not a sufficient
independent-parent population for a model-performance claim.

## Executed checks

The affected regression suite passed 91 tests and two subtests. All 116 exported
expert-prefix targets (97 main-profile targets plus 19 companion targets) passed
the canonical chat audit and teacher-realizability audit. Each selected main
manifest passed the actual GNN training-admission validator. The original
manifest hashes and the held-out cases, means, covariances, labels, parent splits,
noise seeds and replicate counts were checked unchanged. A fresh default bundle
generation also completed with admission enabled and exposed the same 29/31/37
retained training counts.

Receipts: `output/reviewed_wls_admission_20260917/validation_summary.json`,
`filtered_v1/consumer_validation.json`, and
`default_pipeline_probe/bundle_report.json`. No neural model was trained.
